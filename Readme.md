# CommerceIQ – E-commerce Analytics Dashboard

CommerceIQ is a modern e-commerce dashboard designed to monitor and manage online store operations through a clean and interactive interface.

## Features

- Interactive Dashboard
- Order Management
- Product Management
- Customer Management
- Sales Analytics
- Revenue and Order Charts
- Date Range Filtering
- CSV Report Export
- Settings Management
- Responsive UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Font Awesome
- Local Storage
